# dio_projetodois
# Chat Inteligente com PDFs usando IA

## 💡 Visão Geral

Este projeto tem como objetivo usar IA generativa e busca vetorial para permitir a interação com artigos acadêmicos em PDF de forma dinâmica.

## 🧱 Tecnologias Usadas
- LangChain
- FAISS
- OpenAI API
- Streamlit
- PyMuPDF
